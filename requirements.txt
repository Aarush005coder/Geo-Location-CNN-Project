Libraries & Their Role in GeoVision

1. TensorFlow & Keras
What it is:
TensorFlow is an open-source deep learning framework developed by Google. Keras is the high-level API built on top of TensorFlow that makes building neural networks simple and readable.

Why I used it:
It is the backbone of your entire project. I used it to:
- Build the AlexNet-inspired CNN layer by layer
- Compile the model with `Adam` optimizer and `MSE` loss
- Train the model using `model.fit()`
- Add callbacks like `EarlyStopping` and `ReduceLROnPlateau`

My code example:
```python
from tensorflow.keras.layers import Conv2D, Dense, Dropout
from tensorflow.keras.models import Sequential
model = Sequential()
model.add(Conv2D(96, kernel_size=(11,11), strides=4, activation='relu'))
```

2. OpenCV (`cv2`)
What it is:
OpenCV (Open Source Computer Vision Library) is the worlds most popular image processing library, originally developed by Intel.

Why I used it:
Every single image in my project passes through OpenCV. I used it to:
- Decode raw image bytes from `.msg` files into pixel arrays
- Convert BGR color format to RGB for correct display
- Resize all images to a uniform `128×128` size for the model

My code example:
```python
image = cv2.imdecode(image_array, cv2.IMREAD_COLOR)
image = cv2.cvtColor(image, cv2.COLOR_BGR2RGB)
image = cv2.resize(image, (128, 128))
```

4. MessagePack (`msgpack`)
What it is:
MessagePack is a fast binary serialization format — like JSON but much smaller and faster. It is used to store large datasets efficiently.

Why I used it:
My entire dataset is stored in `.msg` shard files. Without msgpack I cannot open or read a single image from the dataset. I used it to:
- Open and unpack each `.msg` shard file
- Stream through records one by one without loading everything into memory
- Extract the `image`, `latitude`, and `longitude` fields from each record

My code example:
```python
with open(file_path, "rb") as f:
    unpacker = msgpack.Unpacker(f, raw=False)
    for item in unpacker:
        image_bytes = item['image']
        lat = item['latitude']
        lon = item['longitude']
```

Matplotlib is Python most widely used data visualization library. It can produce publication-quality plots, charts, and image displays.

6. Scikit-learn
What it is:
Scikit-learn is Pythons go-to machine learning library built on NumPy. It provides hundreds of ML algorithms and utility tools.

Why I used it:
I used only one function from it — but a very important one:
- `train_test_split()` — splits my 1001 images into 80% training (800 images) and 20% testing (200 images) randomly but reproducibly using `random_state=42`

My code example:
